## 📌 Algunos de mis proyectos

### 🚌 [SUBEMISIONERO — Gestión de transporte urbano](https://github.com/TomasMoroz04/Sube-Misionero-C)
Sistema desarrollado en C que simula operaciones de una tarjeta de transporte, incluyendo usuarios, beneficios tarifarios, recargas, viajes y administración.

### 🛠️ [Gestión de instalaciones y órdenes de trabajo](https://github.com/TomasMoroz04/Gestion-Instalaciones-Estructuras-C)
Sistema en C que aplica listas enlazadas, árboles binarios, pilas, colas y persistencia en archivos CSV para administrar servicios y órdenes de trabajo.

### 💳 [Modelo relacional Fintech](https://github.com/TomasMoroz04/Modelo-Relacional-Fintech-SQL)
Diseño de una base de datos para una billetera virtual, con especialización de entidades, normalización, consultas analíticas y operaciones transaccionales en MySQL.

### 🖥️ [Simulador de planificación de CPU y memoria](https://github.com/TomasMoroz04/Simulador-Planificacion-CPU-Memoria)
Proyecto orientado a Sistemas Operativos, con algoritmos de planificación, paginación de memoria, concurrencia y persistencia en Java.

### 🔬 [Investigación sobre optimización CVRP](https://github.com/TomasMoroz04/Investigacion-Optimizacion-CVRP)
Análisis académico del problema de enrutamiento de vehículos capacitados y de distintos enfoques de optimización, incluidos métodos clásicos, inteligencia artificial y computación cuántica.

### 🐾 [Alimentador de mascotas IoT vía Telegram](https://github.com/TomasMoroz04/Alimentador-Mascotas-IoT-Telegram)
Proyecto de hardware y software que integra ESP32, Arduino, sensores y un bot de Telegram para automatizar la dispensación de alimento y agua.
