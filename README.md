## 📌 Proyectos destacados

### 💰 [Finanzas Zero — Showcase de Aplicación Móvil Android](https://github.com/TomasMoroz04/Finanzas-Zero-Showcase)
Showcase y presentación pública de una aplicación móvil nativa para Android enfocada en finanzas personales, desarrollada con Kotlin, Jetpack Compose, Material 3 y Room SQLite bajo una arquitectura *local-first* y 100% offline. Incluye selector mensual, panel de carga rápida, gráficos interactivos y exportación de resúmenes en PDF mediante el Storage Access Framework.

### 🖥️ [Simulador de planificación de CPU y memoria](https://github.com/TomasMoroz04/Simulador-Planificacion-CPU-Memoria)
Simulador interactivo y multihilo en Java Swing de conceptos de Sistemas Operativos: algoritmos FCFS, SJF, SRTF y Round Robin, paginación con MMU y reemplazo FIFO/LRU, y persistencia con JPA, Hibernate y H2.

### 🚌 [SUBEMISIONERO — Gestión de transporte urbano](https://github.com/TomasMoroz04/Sube-Misionero-C)
Sistema desarrollado en C que simula operaciones de una tarjeta de transporte urbano y billetera electrónica, con beneficios tarifarios, recarga de saldo con comprobantes y persistencia en archivos binarios.

### 🛠️ [Gestión de instalaciones y órdenes de trabajo](https://github.com/TomasMoroz04/Gestion-Instalaciones-Estructuras-C)
Sistema en C que implementa listas enlazadas, árboles binarios de búsqueda, pilas y colas con manejo manual de memoria dinámica y persistencia en archivos CSV para administrar órdenes de trabajo y catálogos de servicios.

### 💳 [Modelo relacional Fintech](https://github.com/TomasMoroz04/Modelo-Relacional-Fintech-SQL)
Diseño e implementación de base de datos relacional en MySQL para una plataforma financiera digital, con normalización en 3FN, jerarquías de especialización, consultas analíticas complejas y operaciones transaccionales.

### 🏫 [Análisis funcional y gestión educativa](https://github.com/TomasMoroz04/Analisis-Funcional-Gestion-Educativa)
Proyecto de análisis de sistemas e ingeniería de requisitos para un instituto educativo, con modelado esencial mediante DFD, modelo de datos DER, marco analítico PIECES y especificaciones lógicas de procesos.

### 🐾 [Alimentador de mascotas IoT vía Telegram](https://github.com/TomasMoroz04/Alimentador-Mascotas-IoT-Telegram)
Proyecto integrador de sistemas embebidos que combina ESP32, Arduino UNO, sensores de presión, motor paso a paso y un bot de Telegram con portal cautivo de configuración para automatizar la dispensación de alimento y agua.

### 🔬 [Investigación sobre optimización CVRP](https://github.com/TomasMoroz04/Investigacion-Optimizacion-CVRP)
Estudio académico de investigación sobre la evolución de métodos de resolución del problema de enrutamiento de vehículos capacitados (CVRP), analizando heurísticas clásicas, Deep Learning (NCO/GNN), LLMs y computación cuántica híbrida.

## 🎯 Mi objetivo

Seguir profundizando mis habilidades en desarrollo de software, diseño de sistemas y arquitectura de aplicaciones, participando en proyectos desafiantes y construyendo soluciones que combinen buenas prácticas de programación, pensamiento analítico y tecnología.
